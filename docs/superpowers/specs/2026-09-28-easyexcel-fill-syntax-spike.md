# EasyExcel 模板填充语法 Spike 设计

- **日期**：2026-09-28
- **里程碑**：M2 前置 spike（FR-RD-03 占位符语法冻结前提，评审 H10「M2 前 spike 验证后冻结并出模板编写指南」）
- **状态**：方案已评审通过，用户确认开工

## 一、目标

在正式实现 FR-RD-03 Excel 渲染前，用最小可运行代码验证 EasyExcel 模板填充的占位符语法与分批填充性能，产出三件物：

1. 冻结的占位符语法规范
2. 模板编写指南
3. 可复现的 POC（独立 `spike/easyexcel/` Maven 模块）

## 二、背景与待定语法

PRD FR-RD-03 与设计 spec RD-3 各有草案。经核实，EasyExcel 实际支持两种列表形态 + 单值形态，spike 需把它们定成无歧义规则：

| 形态 | 草案写法 | EasyExcel 语义 |
|---|---|---|
| 单列表填充 | `{.字段名}` | `doFill(list)` / 单 `FillWrapper` |
| 多列表同 sheet | `{别名.字段名}` | `FillWrapper("别名", list)` |
| 单值（取首行） | `{数据集名.字段名}` | 平台自定义解析器在填充前替换 |

**关键风险**：单值 `{数据集.字段}` 与多列表别名 `{别名.字段}` 形状相同。spike 必须给出无歧义的区分规则（否则模板编写者无所适从，评审 H10 未决问题）。

## 三、验证点（POC 内 JUnit 断言）

| # | 验证项 | 冻结结论 |
|---|---|---|
| 0 | 库版本：pin EasyExcel 版本、JDK 21 兼容、FastExcel fork 状况 | 定版本 |
| 1 | 单列表 `{.字段}` 填充 | 定写法 |
| 2 | 多列表同 sheet `{别名.字段}` + `FillWrapper` + `forceNewRow` | 行→支持；不行→冻结「一 sheet 一列表」 |
| 3 | 单值 `{数据集.字段}` 填充前替换，验证与 #2 不冲突 | 定单值写法 |
| 4 | 5 万行 × 20 列分批 `fill()`（不整体物化），计时 ≤30s、堆增量 ≤1GB | 出性能记录 |
| 5 | 产物正确性：回读 xlsx，断言值落对格子 | 出正确性证据 |

## 四、性能口径

FR-RD-03 验收基准为「8 核 16G」；本开发机为 **4 核 16G**。实测值按 4 核标注，并与 8 核基准给出对照说明。
